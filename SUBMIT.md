# Submit after the site is back

CrewAI's public Tool Repository is published with `crewai tool publish --public` after a CrewAI AMP login. That is a public submit. Do not run it while helmswap.com returns HTTP 402, and do not run it without Colby's OK.

Suggested steps, once approved:

1. Create and push `gambrelcolby63/crewai-helmswap` with this package (GitHub push from Colby's account).
2. Colby logs into CrewAI AMP in his own browser.
3. From the package directory: `crewai tool publish --public`.
4. Confirm the listing text has no fee or referral percentages and no comparative claims.

The tool functions can also be used from a local path without publishing, by adding this directory to the agent's environment.
